# Статус устранения расхождений frontend / HTTP API

Прежний аудит описывал состояние до подключения P0–P2. Теперь контракт реализован в коде FastAPI и frontend; актуальные маршруты перечислены в [http_api.md](http_api.md). Этот документ не заменяет OpenAPI.

## P0

Восстановлены доверенный вход/JWT и роли; добавлены регистрация наблюдателя и назначение ролей администратором. Демонстрационный procurement API отключён. Реальные строки рекомендаций содержат SKU, названия и снимок цен; поиск и пагинация выполняются сервером. Добавлены история расчётов, атомарное массовое принятие, создание только выбранных заказов и постоянный список заказов. Frontend использует эти маршруты, сохраняет в Zustand только выбор строк/открытый расчёт.

## P1

Добавлены справочники поставщиков, складов и категорий, история продаж/остатков рекомендации до 24 месяцев, общий журнал транзакционных аномалий, ряды спроса и ABC/XYZ. Политика ABC/XYZ фиксируется в параметрах запуска. Исторические результаты без нужных evidence возвращают явное состояние unavailable. MOQ и кратность проверяются сервером при корректировке, принятии и формировании заказов.

## P2

Добавлены budget_limit/currency, воспроизводимое распределение бюджета целыми упаковками по риску и сохранённые суммы потребности. Неизвестные цены и смешанные валюты отклоняются. Есть серверное What-If превью с явным методом и ограничениями. Расчёт и импорт выполняются через сохраняемую очередь с ответом 202, защищёнными повторными запросами расчёта и читаемым прогрессом.

## Практические ограничения

- Бюджет использует документированную жадную эвристику, а не доказанный глобальный математический оптимум.
- service_level в превью линейно масштабирует сохранённый страховой запас; статистическая гарантия доступности не заявляется. Превью нельзя утвердить как заказ.
- История исходных продаж/остатков доступна до 24 месяцев при наличии импортов; очищенный ряд текущего алгоритма сохраняется за 12 месяцев, available_months сообщает фактическое окно.
- В журнале выбросов находятся сохранённые транзакционные аномалии. Месячные аномалии видны в evidence конкретного объяснения и не подменяют транзакционные записи.
- Прогресс расчёта отражает реальные стадии одной задачи; число обработанных SKU пока не публикуется. При атомарном импорте строки считаются сохранёнными после commit.
- Потребуются пересборка контейнеров, миграция 0003, JWT_SECRET и первый администратор. Инструкция: [authentication.md](authentication.md).
- Тесты и production-сборка не запускались по просьбе пользователя; статические проверки описаны в итоговом сообщении задачи.
