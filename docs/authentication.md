# Вход, регистрация и роли

Авторизация восстановлена по актуальному запросу пользователя. Схемы user_credentials и users создаются миграциями 0001/0002; фоновая очередь требует 0003.

В `.env` нужен случайный JWT_SECRET длиной от 32 байт, общий для всех backend workers. Его можно сгенерировать через `python -c "import secrets; print(secrets.token_urlsafe(48))"`. В текущем рабочем окружении секрет создан в игнорируемом `.env`; репозиторий его не содержит. При отсутствии секрета вход возвращает 503 auth_not_configured, процесс и health остаются доступны. JWT_ACCESS_MINUTES по умолчанию 30.

Первого администратора создайте после запуска контейнеров: `docker compose exec backend python -m backend.infrastructure.bootstrap_admin --username admin`. Пароль (12–256 символов) вводится интерактивно без отображения. Не задавайте пароль аргументом команды.

Публичная форма регистрации создаёт только наблюдателя (viewer). После входа администратор открывает «Сотрудники» и назначает buyer или admin. Нельзя назначить себе права при регистрации либо изменить свою роль через административную форму.

- viewer: просмотр, аналитика, превью, скачивание уже сформированного XLSX.
- buyer: импорт, расчёт, корректировка, принятие, создание, явное утверждение и экспорт заказов.
- admin: все операции buyer и управление ролями сотрудников.

FastAPI проверяет подпись HS256, срок, issuer, audience, UUID пользователя и token_version. Активность и роль читаются из БД на каждом запросе. Пароли хешируются Argon2. Произвольный X-User-ID не доверяется. Logout повышает token_version и отзывает текущие токены пользователя.

Next.js хранит токен в cookie stockwise_access_token с HttpOnly и SameSite=Lax, Secure на HTTPS. BFF проверяет Origin изменяющих запросов, подставляет Bearer и скрывает сам токен от клиентского JavaScript. SSR читает cookie только на серверной границе. При истечении сессии UI возвращается к форме входа; недоступность сервера показывается отдельной ошибкой.

Подробные маршруты: [http_api.md](http_api.md). При Docker-запуске entrypoint применяет `alembic upgrade head`. Пересборка: `docker compose up -d --build`. Тесты и сборка в ходе этой задачи не запускались.
